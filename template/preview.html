Cara Pakai Template (untuk semua bagian)

Setelah template di-ACC, tiap anggota tinggal 3 langkah:

  1. Link CSS & JS template: <link rel="stylesheet" href="../template/template.css"> + <script src="../template/template.js"></script>
  2. Salin kerangka halaman (sidebar & topbar terisi otomatis lewat data-slot)
  3. Tulis konten di dalam <main class="page"> pakai komponen di atas

Menu sidebar diatur terpusat di array MENU pada template.js — satu tempat, semua halaman ikut berubah.
